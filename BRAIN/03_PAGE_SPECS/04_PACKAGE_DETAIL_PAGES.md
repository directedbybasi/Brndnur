# Page Specs D — Package Detail Pages (Routes 19–22)

## All package-detail pages
Each detail page must align with `/packages/` but not blindly copy a disputed price. Package copy must clearly separate: (1) confirmed inclusions, (2) optional or conditional service, (3) government charges, (4) BRNDNUR professional fees, (5) exclusions or owner confirmation items. If details aren't confirmed, use “request a quote” and flag the missing information internally in `10_DECISION_LOG.md`—do not fabricate a polished false offer.

Reusable package layout: compact hero and package summary; intended audience; what's included; not included/depends on circumstances; fee components; customer checklist; 3-step workflow; FAQs; related packages/services; page-specific quote CTA. Use one distinct topic image, then concise content and open columns. Do not use an ecommerce checkout unless one actually exists.

## 19. Individual / MSME Trademark Package `/packages/individual-msme/`
**Audience:** eligible individual or small-business applicants seeking trademark filing support.
**Sections:** package purpose; applicant eligibility caveat; search and class selection; application support; documents; fee breakdown by per-class government charge and professional fee; optional extras; process; FAQs; quote CTA.
**Critical:** confirm current government fees and eligibility for the reduced fee before publishing. MSME status must not be presented as automatic qualification without checking the official criteria. Current pricing sources conflict; see `04_CONTENT_PRICING_AND_TRUST.md`.

## 20. Company / LLP Trademark Package `/packages/company-llp/`
**Audience:** company/LLP applicants.
**Sections:** package overview; company/LLP information and authorisation needed (verify current requirements); scope; fee by class; possible additional class/multiple mark considerations; process; FAQs; quote CTA.
**Critical:** don't reuse Individual/MSME prices. Keep official fee and professional fee separate. Confirm each rate and what's included before publication.

## 21. Food Brand Package `/packages/food-brand/`
**Source package scope:** WhatsApp template describes trademark, Udyam/MSME and FSSAI support for food-related businesses; source displays ₹12,000. Treat price and all inclusions as indicative pending confirmation.
**Sections:** suitable audience/use cases; included service list with conditional FSSAI/business rules; brand search/trademark support; Udyam/MSME and FSSAI portions; information needed; fees and exclusions; package workflow; FAQs; quote CTA.
**Rules:** avoid promising the same FSSAI route for every food business. Clarify if government charges, GST, third-party charges, additional classes or extras are outside the package only after owner confirms.
**Visual:** high-quality food-business packaging/workspace scene in brand palette, separate from legal still-life photos.

**Source package scope:** brand-name search, trademark filing, Udyam/MSME, GST, FSSAI when relevant and general advisory are mentioned; price is shown as “starting ₹18,000”. Treat both scope and price as indicative until confirmed.
