# BRNDNUR Page-Build Rule

1. Read `AGENTS.md` and `BRAIN/00_START_HERE.md`.
2. Consult `BRAIN/01_PAGE_MANIFEST.md` and the matching route spec under `BRAIN/03_PAGE_SPECS/`.
3. For visuals, read `02_DESIGN_SYSTEM.md`; for UI behavior, read `05_COMPONENTS_AND_INTERACTIONS.md`; for images, read `06_IMAGE_AND_ASSET_RULES.md`; for factual/pricing/legal copy, read `04_CONTENT_PRICING_AND_TRUST.md`.
4. Follow `07_BUILD_PLAN_AND_QA.md`; update `10_DECISION_LOG.md` after each batch.
5. Preserve the frozen homepage and three existing reference pages unless directly instructed to change them.
6. Never guess missing details or silently resolve conflicting prices. Verify official facts and mark owner decisions.
7. Use local assets and correct relative paths. Test routes, links, forms, accordions, keyboard behavior and responsive widths before reporting completion.
